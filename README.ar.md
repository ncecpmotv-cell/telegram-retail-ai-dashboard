# 📱 telegram-retail-ai-dashboard — لوحة التحكم (تطبيق تيليجرام المصغّر)

> النسخة العربية من الدليل. [English version](README.md)

**لوحة تحكم بلا خادم (Serverless) لنظام تحليلات التجزئة** — موقع ثابت بالكامل (HTML + Tailwind + JavaScript + Chart.js) يعمل داخل تيليجرام كـ Mini App، ويعرض حالة متجرك الحية ومؤشرات البيع بالتجزئة، ويسمح بتعديل الكاميرات وموجّه الذكاء الاصطناعي، مع لوحة مشرف لإدارة الاشتراكات.

الجهاز المُشغِّل للذكاء الاصطناعي هو المستودع الشقيق
[`poco-retail-ai-core`](https://github.com/ncecpmotv-cell/poco-retail-ai-core) — هذه اللوحة هي النصف الثاني من النظام.

```
┌─────────── الهاتف (الجهاز الحافّي) ───────────┐    ┌── هذا المستودع ──────┐
│ كاميرات ← MiniCPM-V ← SQLite ← المؤشرات      │    │ index.html (المالك)   │
│  └─ sendMessage + pinChatMessage ────────┐    │    │ admin.html (المشرف)   │
└──────────────────────────────────────────┼────┘    │ Telegram WebApp SDK   │
                                           ▼         │ رسوم Chart.js         │
                              قناة تيليجرام الخاصة ◄─┼─ getChat (الحالة)     │
                              (ناقل مجاني)          │  sendMessage (الأوامر) │
                                           ▲         │ مرآة CloudStorage     │
                              الإعدادات والاشتراكات ─┘                       │
                                           └─────────────────────────────────┘
```

> ⚠️ **انحراف موثّق عن خطة المشروع:** الطريقتان `getCloudStorageValues` / `setCloudStorageValues` غير موجودتين في Bot API (تخزين Mini App السحابي متاح للعميل فقط). الحل الفعلي المكافئ: قراءة الرسالة المثبّتة عبر `getChat.pinned_message`، وإرسال الإعدادات عبر `sendData` (داخل تيليجرام) أو قناة بوت ترحيل اختيارية.

## 🚀 التشغيل

### أ) محليًا (تجربة فورية)

```bash
git clone https://github.com/ncecpmotv-cell/telegram-retail-ai-dashboard.git
cd telegram-retail-ai-dashboard
python3 -m http.server 8080
# افتح http://localhost:8080
```

خارج تيليجرام يعمل التطبيق بوضع تجريبي (بيانات وهمية) — لكن بعد إدخال التوكن والقناة في الإعدادات **يقرأ بيانات جهازك الحقيقية من أي متصفح**.

### ب) GitHub Pages (مستحسن للإنتاج)

النشر تلقائي عبر GitHub Actions (`.github/workflows/pages.yml`) عند كل push:
`https://ncecpmotv-cell.github.io/telegram-retail-ai-dashboard/`

### ج) أي استضافة ثابتة أخرى

Netlify / Cloudflare Pages / Vercel — مجلد الجذر فقط، بدون خطوة بناء. استخدم رابط HTTPS الناتج في BotFather.

## 🔗 الربط مع تيليجرام

1. **أنشئ البوت**: [@BotFather](https://t.me/BotFather) ← `/newbot` ← انسخ التوكن
2. **القناة الخاصة**: قناة جديدة ← أضف البوت مشرفًا (نشر + تثبيت)
3. **سجّل التطبيق**: BotFather ← `/newapp` أو زر القائمة ← الرابط أعلاه
4. **أول تشغيل**: الإعدادات ← جسر تيليجرام ← الصق:

| الحقل | القيمة |
|---|---|
| `BOT_TOKEN` | توكن البوت (لقراءة الحالة) |
| `STATE_CHANNEL_ID` | `@username` القناة |
| `ADMIN_ID` | معرفك الرقمي من [@userinfobot](https://t.me/userinfobot) |
| `BRIDGE_SECRET` | (اختياري) نفس قيمة `BRIDGE_SECRET` في `config.env` بالجهاز لتوقيع HMAC |

## 🧭 الصفحات

| الصفحة | لمن | ماذا تفعل |
|---|---|---|
| `index.html` | صاحب المتجر | شارة الإشغال الحية (Normal/Congested/Critical/Blocked/Offline)، مؤشر الازدحام، التنبيهات، خط الاشتراك، رسوم ساعات الذروة واتجاه الزوار، الكفاءة، فجوات التوظيف، إعدادات الكاميرات والموجّه |
| `admin.html` | المشرف (`ADMIN_ID`) | مراقبة الجهاز (الحالة، آخر ظهور، الانتهاء)، قائمة المستخدمين، منح الاشتراكات (+30/+90/+365 يومًا) |

## ✨ ميزات اللوحة

- **واجهة عربية RTL** — زر تبديل اللغة (EN/عربي) أعلى الصفحة، مع اتجاه النص تلقائيًا
- **كشف انقطاع الجهاز** — شارة "غير متصل" إذا لم يُحدَّث الجهاز الحالة خلال 10 دقائق
- **مقاييس الأداء** — زمن آخر استدلال، مدة التشغيل، عدد الاستدلالات الناجحة
- **توقيع HMAC** — عند ضبط `BRIDGE_SECRET` تُوقَّع الأوامر وتُتحقق الحالة المستلمة
- **وضع تجريبي كامل** — كل الواجهة قابلة للتجربة في متصفح عادي بدون تيليجرام
- **بطاقات المناطق** — زوار اليوم والعدد الحالي لكل كاميرا (منطقة): الكاونتر، المدخل، الجلسات
- **التوظيف المقترح** — خطة ساعية لأعداد الموظفين من متوسط 7 أيام (أشرطة بيانية)
- **صحة الكاميرات** — مؤشر 🟢/🟡/🔴 لكل كاميرا من عدّادات الجهاز
- **تنبيهات المحادثة** — ازدحام حرج، فجوة توظيف جديدة، أو نشاط خارج ساعات العمل تصلك فورًا

## 🔐 ملاحظات أمنية

- التوكن يُدخل وقت التشغيل ويُخزن في CloudStorage الخاص بالمستخدم — لا يوجد في المستودع أبدًا
- داخل تيليجرام تُرسل الأوامر عبر `sendData` (بلا توكن في الواجهة للكتابة)؛ من المتصفح العادي تحتاج بوت ترحيل (relay) لأن تيليجرام لا يردّد منشورات البوت لنفسه
- `BRIDGE_SECRET` يمنع تزوير أوامر الاشتراكات حتى لو تسرّب التوكن

## 🧯 استكشاف الأخطاء

| العَرَض | الحل |
|---|---|
| "لا توجد تحليلات بعد" | تأكد أن خدمة الجهاز تعمل وأن الرسالة المثبّتة موجودة في القناة |
| فشل قراءة القناة | تحقق من التوكن ومن أن البوت مشرف في القناة |
| `sendData` يفشل | يعمل فقط عند الفتح من محادثة البوت — هيّئ التوكن والقناة بدلًا منه |
| الرسوم لا تظهر | تأكد من اتصال CDN أو انسخ Chart.js محليًا |
